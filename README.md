# homebrew-hotdocs

Homebrew tap for [hotdocs](https://github.com/liam-selfors/hotdocs): spec-driven agentic development, specs in, verified code out.

```
brew install liam-selfors/hotdocs/hotdocs
```

The formula installs the release's sdist from PyPI, checked against its pinned `sha256`, with its pinned dependencies, into a private virtual environment. `node` is a recommended dependency, needed only for components that declare JavaScript assets; skip it with `--without-node`.

hotdocs is alpha software. See its [QUICKSTART](https://github.com/liam-selfors/hotdocs/blob/main/QUICKSTART.md) to start a project.
